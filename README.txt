PUBLICAÇÃO NO GITHUB PAGES
1. Crie uma conta em https://github.com, se necessário.
2. Crie um repositório público, por exemplo: pilulas-reflexivas.
3. Envie TODO o conteúdo desta pasta para a raiz do repositório.
4. No GitHub, abra Settings > Pages.
5. Em Build and deployment, escolha Deploy from a branch.
6. Selecione a branch main e a pasta /(root), depois Save.
7. Aguarde o endereço público ser exibido pelo GitHub Pages.

ARQUIVOS PRINCIPAIS
- index.html: página principal
- style.css: aparência
- script.js: busca, filtros e montagem do catálogo
- catalogo.js / catalogo.json / catalogo.csv: metadados
- audio/: arquivos sonoros
- img/: fotografia do autor
