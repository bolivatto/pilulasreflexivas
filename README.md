# Pílulas Reflexivas — versão 2

Site público de Bruno Olivatto, estruturado para atualização contínua no GitHub Pages.

## O que mudou na versão 2

- acervo de Pílulas Reflexivas convertido em uma coleção Jekyll;
- páginas individuais para cada áudio;
- nova seção `Colunas Publicadas`;
- página `Temas`, integrando áudios e textos;
- modelos prontos para novas pílulas e novas colunas;
- atualização contínua por arquivos Markdown, sem necessidade de alterar o código do site;
- preservação dos 47 áudios já publicados;
- busca e filtros no acervo sonoro.

Leia `ATUALIZACAO.md` antes de acrescentar novos conteúdos.

## Para substituir a versão atual no GitHub

Copie todo o conteúdo desta pasta para a raiz do repositório `pilulasreflexivas`, substituindo os arquivos antigos quando solicitado. Depois faça Commit + Push pelo GitHub Desktop.

O GitHub Pages deverá estar configurado para publicar a branch `main` a partir da raiz (`/(root)`). O GitHub Pages processará automaticamente o Jekyll.

## Endereço do repositório

A configuração atual usa `baseurl: "/pilulasreflexivas"`, correspondente ao nome do repositório mostrado no GitHub Desktop. Se o repositório for renomeado ou se você passar a usar domínio próprio, ajuste esse campo em `_config.yml`.


## Colunas incorporadas

A versão atual inclui 8 colunas em `_colunas/` e os respectivos PDFs em `pdf/colunas/`. Quando a data ou o veículo de publicação não estavam explicitamente informados nos PDFs recebidos, esses campos foram deixados em branco para evitar inferências editoriais.
